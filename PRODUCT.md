# Produit

Application Android de comparaison visuelle départ/retour de scooters, pour employés de petites agences. Usage répété, hors ligne, sans matériel spécialisé. Le brief utilisateur constitue l’autorité produit ; aucune interview terrain n’a encore eu lieu.

MVP0 : quatre clips par état, extraction automatique, comparaison expérimentale, revue humaine, export. Aucun dommage certifié, aucune facturation IA. Langue française pour test initial. Hypothèses à vérifier : durée acceptable, quatre faces suffisantes, gain de temps, volonté de payer.
